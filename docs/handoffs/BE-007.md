## Key Changes Implemented

### 1. Domain Layer (`src/Domain/Entities/Property.cs`)
- Added `Purpose` property (`public string Purpose { get; set; } = "Sale";`) supporting `Sale` (للبيع) and `Rent` (للإيجار).
- Added `City` property (`public string City { get; set; } = "حلب";`).

### 2. Infrastructure Layer (`src/Infrastructure/Data/`)
- **EF Core Model Configuration (`ApplicationDbContext.cs`)**:
  - Configured property constraints and default values for `Purpose` (max length 50, default `"Sale"`) and `City` (max length 100, default `"حلب"`).
  - Configured 6 EF Core database performance indexes:
    - `IX_Properties_Category_Status`: Composite index on `(Category, Status)`
    - `IX_Properties_CityArea_Status`: Composite index on `(CityArea, Status)`
    - `IX_Properties_Purpose_Status`: Composite index on `(Purpose, Status)`
    - `IX_Properties_Price`: Index on `Price`
    - `IX_Properties_AreaSquareMeters`: Index on `AreaSquareMeters`
    - `IX_Properties_CreatedAt`: Index on `CreatedAt`
- **Seed Data (`ApplicationDbContextInitialiser.cs`)**:
  - Updated all 5 seed property records with explicit `Purpose` (`Sale` / `Rent`) and `City` (`حلب`) values.

### 3. Application Layer (`src/Application/`)
- **`PropertyDto.cs`**:
  - Added `Purpose` and `City` properties to the DTO model.
- **`GetPropertiesQuery.cs`**:
  - Expanded `GetPropertiesQuery` record to support all search & filter parameters: `SearchTerm`, `City`, `CityArea`, `Category`, `Purpose`, `MinPrice`, `MaxPrice`, `MinArea`, `MaxArea`, `Bedrooms`, `Bathrooms`, `Status`, `SortBy`, `PageNumber`, `PageSize`.
  - Built an EF Core query pipeline utilizing `AsNoTracking()`.
  - Filter logic `.Where(...)` is applied **BEFORE** `CountAsync()` and `Skip().Take()`.
  - Excludes `Archived` status by default unless a specific status filter is supplied.
  - Implemented sorting options: `date_desc`, `date_asc`, `price_asc`, `price_desc`, `area_desc`, `area_asc`.
  - Execution via `ToListAsync()` occurs **AFTER** `Skip().Take()` via `PaginatedList<PropertyDto>.CreateAsync()`.
- **Commands & Queries Updated**:
  - `CreatePropertyCommand.cs` & `CreatePropertyCommandValidator.cs`: Added `Purpose` & `City` support and validation rules.
  - `UpdatePropertyCommand.cs` & `UpdatePropertyCommandValidator.cs`: Added `Purpose` & `City` support and validation rules.
  - `GetPropertyByIdQuery.cs`, `GetMyPropertiesQuery.cs`, `GetUserFavoritesQuery.cs`: Included `Purpose` and `City` in DTO projections.

### 4. Web Layer (`src/Web/Endpoints/PropertyEndpoints.cs`)
- Updated `GET /api/properties` endpoint query parameter binding to map `searchTerm`, `city`, `cityArea`, `category`, `purpose`, `minPrice`, `maxPrice`, `minArea`, `maxArea`, `bedrooms`, `bathrooms`, `status`, `sortBy`, `pageNumber`, and `pageSize`.
- Updated `UpdatePropertyRequest` payload to accept `purpose` and `city`.
