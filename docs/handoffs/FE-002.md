## Created / Updated Files
1. `src/Web/ClientApp/src/app/core/models/property.model.ts`
   - Added TypeScript interfaces matching `docs/api-contract.md`:
     - `Property`: ID (UUID string), title, description, price, category, cityArea, address, bedrooms, bathrooms, areaSquareMeters, imageUrls, status, isFeatured, createdAt.
     - `PropertyFilterParams`: searchTerm, category, cityArea, minPrice, maxPrice, pageNumber, pageSize.
     - `PaginatedResult<T>`: items, totalCount, pageNumber, pageSize, totalPages.
     - `CreatePropertyRequest`: Create property payload.
     - `PropertyCategory` & `PropertyStatus` union types.

2. `src/Web/ClientApp/src/app/core/services/property.service.ts`
   - Injected `HttpClient` to communicate with backend `/api/properties`.
   - Methods implemented:
     - `getProperties(params?: PropertyFilterParams): Observable<PaginatedResult<Property>>`
     - `getPropertyById(id: string): Observable<Property>`
     - `createProperty(dto: CreatePropertyRequest): Observable<Property>`
   - Robust offline/error mock fallback handling filtering by `searchTerm`, `category`, `cityArea`, `minPrice`, `maxPrice`, and `pageNumber` / `pageSize` when API server is unreachable.

3. `src/Web/ClientApp/src/app/features/properties/property-card/property-card.component.ts` & `.html`
   - Standalone Angular component displaying individual property cards.
   - Signal input: `property = input.required<Property>()`.
   - Controls & badges:
     - Featured property badge (`⭐ مميز`).
     - Status badge (`Available` -> `متاح`, `Sold` -> `مباع`, `Rented` -> `مؤجر`).
     - Category tag (`Apartment` -> `🏢 شقة سكنية`, `Villa` -> `🏰 فيلا`, `Commercial` -> `💼 تجاري / مكتب`, `Land` -> `🏞️ أرض`).
     - Location (city area in Aleppo & address).
     - Specification badges (bedrooms 🛏️, bathrooms 🚿, area 📐).
     - Image error handling with default image fallback.
     - RTL Arabic layout styled with Tailwind CSS.

4. `src/Web/ClientApp/src/app/features/properties/property-list/property-list.component.ts` & `.html`
   - Standalone Angular component for property search & grid visualization.
   - Signal-based state management:
     - `searchTerm`, `category`, `cityArea`, `minPrice`, `maxPrice`, `pageNumber`, `pageSize`, `properties`, `totalCount`, `totalPages`, `isLoading`, `errorMessage`.
   - Filters:
     - Text search input.
     - Category select dropdown (`الكل`, `شقق سكنية`, `فيلات`, `تجاري / مكاتب`, `أراضي`).
     - Aleppo city area select dropdown (`الشهباء`, `العزيزية`, `الفرقان`, `السبيل`, `السريان`, `حلب الجديدة`, `المحافظة`).
     - Price range inputs (Min Price / Max Price).
     - Reset filters button.
   - UI States:
     - Loading skeleton cards.
     - Empty results state with friendly Arabic retry prompt.
     - Error banner with retry trigger.
     - Pagination bar supporting page navigation and total count display.
