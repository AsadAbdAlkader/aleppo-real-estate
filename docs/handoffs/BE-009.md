## Key Changes Implemented

### 1. Application Layer DTO & Entities (`src/Application/Properties/` & `src/Domain/Entities/`)

- **DTO Model Update (`src/Application/Properties/Dtos/PropertyDto.cs`)**:
  - Added `OwnerName` (`string?`) and `OwnerEmail` (`string?`) properties.
  - Ensures no sensitive user information (such as `PasswordHash`) is exposed in any response.

- **Domain Entity Enhancement (`src/Domain/Entities/Property.cs`)**:
  - Added `OwnerGuid` computed property (`Guid?`) to seamlessly bridge `OwnerId` string format with `User.Id` (`Guid`) for Entity Framework Core relationship mapping.

### 2. CQRS Query & Handlers (`src/Application/Properties/`)

- **Refined `GetPropertyByIdQuery.cs` (`src/Application/Properties/Queries/GetPropertyById/GetPropertyByIdQuery.cs`)**:
  - Included `Owner` navigation property with `.AsNoTracking()` and `.Include(p => p.Owner)`.
  - Added Archived status guard: Returns `null` (yielding `404 Not Found`) if the property record does not exist OR if `property.Status == "Archived"` (case-insensitive check).
  - Projected `OwnerName` (formatted as `${property.Owner.FirstName} ${property.Owner.LastName}` trimmed) and `OwnerEmail` (`property.Owner.Email`).

- **Updated Projections in Queries & Commands**:
  - `GetPropertiesQuery.cs`: Updated LINQ expression projections to automatically map `OwnerName` and `OwnerEmail` via LEFT JOIN.
  - `GetMyPropertiesQuery.cs`: Updated LINQ projection to include `OwnerName` and `OwnerEmail`.
  - `GetUserFavoritesQuery.cs`: Updated LINQ projection to include `OwnerName` and `OwnerEmail`.
  - `CreatePropertyCommand.cs`: Updated handler to populate `OwnerName` and `OwnerEmail` when property owner exists.
  - `UpdatePropertyCommand.cs`: Updated handler to include `Owner` navigation and return populated `OwnerName` and `OwnerEmail`.

### 3. Infrastructure Layer (`src/Infrastructure/Data/ApplicationDbContext.cs`)

- Configured EF Core relationship mapping for `Property.Owner`:
  - Mapped foreign key `HasForeignKey(p => p.OwnerGuid)` linking `Property` to `User.Id`.
  - Removed `entity.Ignore(p => p.Owner)` so navigation property `.Include(p => p.Owner)` can be evaluated cleanly at runtime.

### 4. Web API Layer (`src/Web/Endpoints/PropertyEndpoints.cs`)

- Updated GET `/api/properties/{id}` 404 response payload message to match `docs/api-contract.md`:
  - `{ "error": "Property with ID {id} was not found or is no longer available." }`
