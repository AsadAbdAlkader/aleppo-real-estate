4. **CQRS Layer (`src/Application/Notifications/`):**

     - `NotificationDto.cs`: `id`, `title`, `message`, `type`, `referenceId`, `isRead`, `createdAt`.
     - `UnreadCountDto.cs`: `unreadCount`.
   - **Queries:**
     - `GetNotificationsQuery.cs`: Filters by `UserId == currentUserId`, optional `unreadOnly` filter, orders by `CreatedAt` descending, uses `AsNoTracking()` and returns `PaginatedList<NotificationDto>`.
     - `GetUnreadNotificationsCountQuery.cs`: Counts unread notifications for current user.
   - **Commands:**
     - `MarkNotificationAsReadCommand.cs`: Validates notification existence and ownership (`UserId == currentUserId`). Sets `IsRead = true` if valid; returns `false` if missing or owned by another user (triggering 404 in Endpoint).

5. **Web API Endpoints (`src/Web/Endpoints/NotificationEndpoints.cs`):**
   - `GET /api/notifications` (`.RequireAuthorization()`): Paginated list of notifications with optional `unreadOnly` parameter.
   - `GET /api/notifications/unread-count` (`.RequireAuthorization()`): Total unread count.
   - `PUT /api/notifications/{id:guid}/read` (`.RequireAuthorization()`): Marks single notification as read, returning `404 Not Found` if missing or unowned.
   - `PUT /api/notifications/read-all` (`.RequireAuthorization()`): Marks all notifications for current user as read.
   - Registered endpoints in `Program.cs` via `app.MapNotificationEndpoints()`.
