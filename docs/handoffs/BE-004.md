## Summary of API Endpoints Added

| Endpoint | Method | Auth Required | Description |
|---|---|---|---|
| `/api/favorites/{propertyId}` | `POST` | Yes (`Bearer`) | Add property to favorites |
| `/api/favorites/{propertyId}` | `DELETE` | Yes (`Bearer`) | Remove property from favorites |
| `/api/favorites` | `GET` | Yes (`Bearer`) | Get all favorited properties of current user |
| `/api/inquiries` | `POST` | Yes (`Bearer`) | Submit an inquiry for a property |
| `/api/inquiries/my` | `GET` | Yes (`Bearer`) | Get all submitted inquiries of current user |
