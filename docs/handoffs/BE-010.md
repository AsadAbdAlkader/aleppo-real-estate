## Key Changes Implemented

### 1. Domain Entities (`src/Domain/Entities/`)
- **`Agency.cs`**:
  - Properties: `Id` (Guid), `Name`, `Description`, `PhoneNumber`, `Address`, `CityArea`, `LogoUrl`, `LicenseNumber`, `CreatedAt`, `UpdatedAt`.
  - Relationship: `ICollection<AgentProfile> AgentProfiles`.
- **`AgentProfile.cs`**:
  - Properties: `Id` (Guid), `UserId` (string, `nvarchar(450)`), `UserGuid` (Guid backing FK), `User? User`, `AgencyId` (Guid?, nullable), `Agency? Agency`, `Bio`, `PublicPhone`, `CreatedAt`, `UpdatedAt`.

### 2. Entity Framework Core Mapping & Migration (`src/Infrastructure/`)
- **DbContext & Interface (`IApplicationDbContext.cs` & `ApplicationDbContext.cs`)**:
  - Added `DbSet<Agency> Agencies` and `DbSet<AgentProfile> AgentProfiles`.
  - Configured EF Core relations & performance indexes:
    - `AgentProfile` 1-to-1 with `User` (`IX_AgentProfiles_UserId` unique index).
    - `AgentProfile` 0..1-to-Many `Agency` (`IX_AgentProfiles_AgencyId` FK index with `DeleteBehavior.SetNull`).
    - Indexes on `Agency.Name` (`IX_Agencies_Name`) and `Agency.CityArea` (`IX_Agencies_CityArea`).
- **EF Core Migration (`src/Infrastructure/Migrations/20260927195354_AddAgencyAndAgentProfile.cs`)**:
  - Created migration `AddAgencyAndAgentProfile` using `IDesignTimeDbContextFactory<ApplicationDbContext>`.
- **Database Initialiser & Seeding (`ApplicationDbContextInitialiser.cs`)**:
  - Seeded demo agencies: `"مكتب تجريبي 01"` (Id: `3fa85f64-5717-4562-b3fc-2c963f66b333`) and `"مكتب تجريبي 02"` (Id: `3fa85f64-5717-4562-b3fc-2c963f66b444`).
  - Seeded demo agent profile for `"agent@aleppo.com"` linked to `"مكتب تجريبي 01"`.

### 3. Application CQRS Layer (`src/Application/Agents/` & `src/Application/Agencies/`)
- **DTO Models**:
  - `AgentDto.cs`, `AgentDetailsDto.cs`, `AgentProfileResponseDto.cs`.
  - `AgencyDto.cs`, `AgencyDetailsDto.cs`.
  - Enforced security: No sensitive fields (`Email`, `PasswordHash`, `Tokens`) present in public agent/agency DTOs.
- **Queries**:
  - `GetAgentsQuery.cs`: Paginated list of agents filtering by `searchTerm` and `cityArea`. Projects `activePropertiesCount` in EF Core context projection without N+1 query loops. Uses `.AsNoTracking()`.
  - `GetAgentByIdQuery.cs`: Retrieves detailed agent profile by User ID.
  - `GetAgentPropertiesQuery.cs`: Paginated list of active, non-archived properties owned by agent.
  - `GetAgenciesQuery.cs`: Paginated list of agencies projecting `agentsCount` and `activePropertiesCount`.
  - `GetAgencyByIdQuery.cs`: Retrieves agency details by Agency ID along with associated `Agents` list.
- **Commands & Validation**:
  - `UpdateAgentProfileCommand.cs`: Allows agent to update their own `Bio`, `PublicPhone`, and `AgencyId`.
  - `UpdateAgentProfileCommandValidator.cs`: Validates field constraints (max lengths).
  - Role Enforcement: Enforces `Agent` or `Admin` role. Returns `403 Forbidden` if invoked by `Buyer` role.

### 4. Web Endpoints (`src/Web/Endpoints/`)
- **`AgentEndpoints.cs`**:
  - `GET /api/agents` (Public)
  - `GET /api/agents/{id}` (Public)
  - `GET /api/agents/{id}/properties` (Public)
  - `PUT /api/agents/me` (`.RequireAuthorization()`, Enforces `Agent`/`Admin` role, returns `403 Forbidden` for `Buyer`).
- **`AgencyEndpoints.cs`**:
  - `GET /api/agencies` (Public)
  - `GET /api/agencies/{id}` (Public)
- **`Program.cs`**: Registered `MapAgentEndpoints()` and `MapAgencyEndpoints()`.
