# BE-013 Handoff Report: User Profile Entity Field, CQRS Queries/Commands & Security Settings Endpoints

## Task Summary
Task BE-013 implements user profile management and security settings endpoints for Aleppo Real Estate.

---

## Changes Implemented

### 1. Domain Entity (`src/Domain/Entities/User.cs`)
- Added optional property `public string? PhoneNumber { get; set; }`.

### 2. Infrastructure & EF Core Migration (`src/Infrastructure/Data/ApplicationDbContext.cs` & `src/Infrastructure/Migrations/`)
- Configured `PhoneNumber` with maximum length 50 in `ApplicationDbContext.cs`.
- Generated EF Core Migration `AddUserPhoneNumber`.

### 3. CQRS Layer (`src/Application/Users/`)
- **DTO**: `src/Application/Users/Dtos/UserProfileDto.cs`
  - Properties: `Id`, `Email`, `FirstName`, `LastName`, `Role`, `PhoneNumber`, `CreatedAt`.
- **Query**: `src/Application/Users/Queries/GetUserProfile/GetUserProfileQuery.cs`
  - Inputs: `CurrentUserId` (Guid).
  - Uses `.AsNoTracking()` to retrieve user profile information.
- **Command 1**: `src/Application/Users/Commands/UpdateUserProfile/`
  - `UpdateUserProfileCommand.cs`: Updates `FirstName`, `LastName`, `PhoneNumber` and sets `UpdatedAt = DateTime.UtcNow`.
  - Enforces strict immutability: `Email`, `Role`, `Id`, `PasswordHash`, `CreatedAt` CANNOT be altered.
  - `UpdateUserProfileCommandValidator.cs`: Validates `FirstName` & `LastName` required (max 100), `PhoneNumber` optional (max 50).
- **Command 2**: `src/Application/Users/Commands/ChangePassword/`
  - `ChangePasswordCommand.cs`: Verifies current password using `IPasswordHasher.VerifyPassword`. If invalid, returns failure result with message `"كلمة المرور الحالية غير صحيحة."`. If valid, hashes new password using `IPasswordHasher.HashPassword`, updates `PasswordHash`, and sets `UpdatedAt = DateTime.UtcNow`.
  - `ChangePasswordCommandValidator.cs`: Validates `CurrentPassword` & `NewPassword` required. Enforces `NewPassword` minimum length of 6 characters matching registration rules.

### 4. ASP.NET Core Web Endpoints (`src/Web/Endpoints/UserEndpoints.cs`)
- Mapped endpoints requiring authorization (`.RequireAuthorization()`):
  - `GET /api/users/profile` -> `GetUserProfileQuery(currentUserId)`
  - `PUT /api/users/profile` -> `UpdateUserProfileCommand(currentUserId, req.FirstName, req.LastName, req.PhoneNumber)`
  - `PUT /api/users/change-password` -> `ChangePasswordCommand(currentUserId, req.CurrentPassword, req.NewPassword)` (Returns 400 Bad Request if current password is incorrect).
- Registered `app.MapUserEndpoints()` in `src/Web/Program.cs`.

### 5. Unit Testing & Verification (`tests/Application.UnitTests/Users/UserProfileTests.cs`)
- Added 7 comprehensive xUnit unit tests verifying:
  - `GetUserProfileQueryHandler` retrieval.
  - `UpdateUserProfileCommandHandler` field updates, timestamp updating, and immutability of system fields.
  - `UpdateUserProfileCommandValidator` validation rules.
  - `ChangePasswordCommandHandler` successful password changes.
  - `ChangePasswordCommandHandler` rejection of incorrect current passwords.
  - `ChangePasswordCommandValidator` 6-character minimum length constraint.
