## Key Changes Implemented

### 1. Application Layer (`src/Application/Dashboard/`)

- **DTO Models (`src/Application/Dashboard/Dtos/`)**:
  - `DashboardUserDto.cs`: User profile representation (`Id`, `Email`, `FirstName`, `LastName`, `Role`).
  - `DashboardStatsDto.cs`: Aggregated dashboard metrics (`MyPropertiesCount`, `ActivePropertiesCount`, `ArchivedPropertiesCount`, `FavoritesCount`, `MyInquiriesCount`).
  - `DashboardRecentPropertyDto.cs`: Projection for user's recently listed properties (`Id`, `OwnerId`, `Title`, `Price`, `Category`, `CityArea`, `Status`, `CreatedAt`, `ImageUrls`).
  - `DashboardRecentFavoriteDto.cs`: Projection for user's recently bookmarked favorite properties (`Id`, `Title`, `Price`, `Category`, `CityArea`, `Status`, `ImageUrls`).
  - `DashboardRecentInquiryDto.cs`: Projection for user's recently submitted property inquiries (`Id`, `PropertyId`, `PropertyTitle`, `Message`, `PhoneNumber`, `CreatedAt`).
  - `DashboardDto.cs`: Composite container for User, Stats, RecentProperties, RecentFavorites, and RecentInquiries.

- **CQRS Query & Handler (`src/Application/Dashboard/Queries/GetUserDashboard/GetUserDashboardQuery.cs`)**:
  - `GetUserDashboardQuery(Guid UserId) : IRequest<DashboardDto?>`
  - `GetUserDashboardQueryHandler`:
    - Validates user existence.
    - Aggregates stats using EF Core `AsNoTracking()` for high efficiency.
    - Aggregates stats:
      - `myPropertiesCount`: Count of properties where `OwnerId == UserId.ToString()`.
      - `activePropertiesCount`: Count of user's properties where `Status != "Archived"`.
      - `archivedPropertiesCount`: Count of user's properties where `Status == "Archived"`.
      - `favoritesCount`: Count of `FavoriteProperty` entries for user `UserId`.
      - `myInquiriesCount`: Count of `PropertyInquiry` entries for user `UserId`.
    - Projects Top 5 recent items:
      - `recentProperties`: Top 5 properties created by user, ordered by `CreatedAt` descending.
      - `recentFavorites`: Top 5 favorite properties bookmarked by user, ordered by `CreatedAt` descending.
      - `recentInquiries`: Top 5 inquiries submitted by user, ordered by `CreatedAt` descending.
    - Enforces strict 100% user data isolation across all queries.

### 2. Web API Layer (`src/Web/Endpoints/DashboardEndpoints.cs`)

- Created `DashboardEndpoints.cs` mapping `GET /api/dashboard`.
- Enforces `.RequireAuthorization()`.
- Extracts `currentUserId` from claims (`user.GetUserId()`) and returns `401 Unauthorized` if unauthenticated.
- Dispatches `GetUserDashboardQuery(userId.Value)` via MediatR.
- Mapped `app.MapDashboardEndpoints()` in `src/Web/Program.cs`.
