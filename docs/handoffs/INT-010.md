## 1. Audit Scope & Key Verification Checklist

1. **Buyer Restrictions & Data Privacy Audit:**

   - Verified `InquiryDto` strictly omits `AgentNotes`.
   - Verified Buyers cannot change status or edit notes (`PUT /api/inquiries/{id}/status` requires property ownership).
   - Verified Buyers cannot view other users' inquiries.

2. **Property Owner Isolation Audit (`Property.OwnerId == currentUserId`):**
   - Verified `GET /api/inquiries/received` returns inquiries for properties owned by the current user (`Property.OwnerId == currentUserId`).
   - Verified Property Owners CANNOT view inquiries for properties owned by another user.
   - Verified `PUT /api/inquiries/{id}/status` checks ownership and returns `403 Forbidden` if an owner attempts to edit an inquiry on a property owned by someone else.

3. **Status & Timestamp Audit:**
   - Verified status transitions (`New` ➔ `Contacted` ➔ `Closed`).
   - Verified status update refreshes `UpdatedAt = DateTime.UtcNow` timestamp.
   - Verified `AgentNotes` is saved (max 2000 chars) and visible exclusively to the property owner.

4. **HTTP Endpoints Verification:**
   - `POST /api/inquiries` ➔ `201 Created` with status `"New"`.
   - `GET /api/inquiries/my` ➔ `200 OK` (Buyer inquiries list with status badges).
   - `GET /api/inquiries/received` ➔ `200 OK` (Property owner inquiries list with buyer phone, message, status, agentNotes, pagination, and status filter).
   - `PUT /api/inquiries/{id}/status` ➔ `200 OK` for property owner, `403 Forbidden` for non-owners.
