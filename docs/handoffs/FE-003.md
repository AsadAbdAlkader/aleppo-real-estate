## Created & Updated Files

1. `src/Web/ClientApp/src/app/core/models/auth.model.ts`
   - Data contracts matching `docs/api-contract.md`:
     - `LoginRequest`: `email`, `password`.
     - `RegisterRequest`: `email`, `password`, `firstName`, `lastName`, `role` (`Buyer`, `Agent`, `Admin`).
     - `AuthResponse`: `id`, `email`, `firstName`, `lastName`, `role`, `token`, `expiresAt`.
     - `User`: `id`, `email`, `firstName`, `lastName`, `role`.

2. `src/Web/ClientApp/src/app/core/services/auth.service.ts`
   - Angular Signals auth state management:
     - `currentUser` (`Signal<User | null>`) initialized from LocalStorage.
     - `isAuthenticated` (`Signal<boolean>`) computed from `currentUser() !== null`.
     - `userRole` (`Signal<string | null>`) computed from `currentUser()?.role ?? null`.
   - Methods:
     - `login(credentials: LoginRequest): Observable<AuthResponse>`
     - `register(data: RegisterRequest): Observable<AuthResponse>`
     - `getCurrentUser(): Observable<User>`
     - `logout(): void`
     - `getToken(): string | null`
   - Features: JWT LocalStorage persistence (`auth_token`, `auth_user`) and dev-mode fallback mechanism for seamless offline/dev testing when backend API is unreachable.

3. `src/Web/ClientApp/src/app/core/interceptors/auth.interceptor.ts`
   - Functional HTTP interceptor (`HttpInterceptorFn`).
   - Retrieves token from `AuthService` and attaches `Authorization: Bearer <token>` to outgoing HTTP requests.

4. `src/Web/ClientApp/src/app/core/guards/auth.guard.ts`
   - Functional route guard (`CanActivateFn`).
   - Checks `authService.isAuthenticated()`. If false, redirects to `/login` preserving `returnUrl` query parameter.

5. `src/Web/ClientApp/src/app/app.config.ts`
   - Registered `provideHttpClient(withInterceptors([authInterceptor]))`.

6. `src/Web/ClientApp/src/app/features/auth/login/login.component.ts` & `.html`
   - Standalone Angular component for user authentication.
   - ReactiveForm with Arabic validation rules (`required`, `email`, `minlength`).
   - Displays error banners, submit spinner, and links to `/register`.
   - Tailwind CSS styling and RTL layout support.

7. `src/Web/ClientApp/src/app/features/auth/register/register.component.ts` & `.html`
   - Standalone Angular component for user registration.
   - ReactiveForm with full name, email, password, and Role selection (`مشتري / باحث عن عقار`, `وكيل عقاري / صاحب مكتب`, `مدير النظام`).
   - Modern Angular control flow syntax (`@if`).
   - Tailwind CSS styling and RTL layout.

8. `src/Web/ClientApp/src/app/core/components/header/header.component.ts` & `.html`
   - Standalone header/navbar component using `AuthService` signals.
   - Dynamically displays:
     - Anonymous mode: `تسجيل الدخول` (Login) and `إنشاء حساب` (Register) links.
     - Authenticated mode: User full name, role badge (`مشتري`, `وكيل عقاري`, `مدير النظام`), `إضافة عقار` button (for agents/admins), and `تسجيل الخروج` (Logout) button.

9. `src/Web/ClientApp/src/app/app.ts`, `app.html`, `app.routes.ts`, `landing.component.html`
   - Integrated `<app-header />` globally into `app.html`.
   - Registered `/login` and `/register` routes in `app.routes.ts`.
   - Removed duplicated static header from landing page.

10. `src/Web/ClientApp/src/app/features/auth/auth.spec.ts`
   - Unit test suite covering `AuthService` (login/register/logout/dev fallback), `authInterceptor` (header attachment), `authGuard` (route protection), `LoginComponent`, `RegisterComponent`, and `HeaderComponent` (dynamic state rendering).
