## Key Changes & Implementations

### 1. Application Layer DTOs & Models (`src/Application/Properties/`)
- **`ImageUploadResponseDto.cs`**:
  - DTO containing `PropertyId` (`Guid`), `ImageUrls` (`List<string>`), and `PrimaryImageUrl` (`string?` pointing to index 0).
- **`PropertyCommandResult.cs`**:
  - Added `BadRequest` enum status to `PropertyCommandStatus`.
  - Added `PropertyImageResult` wrapper supporting `Success`, `NotFound`, `Forbidden`, and `BadRequest` results.

### 2. CQRS Commands & Validators (`src/Application/Properties/Commands/`)
- **`UploadPropertyImagesCommand.cs` & `UploadPropertyImagesCommandValidator.cs`**:
  - Enforces property ownership check (`OwnerId == currentUserId` or `IsAdmin`). Returns `404 Not Found` if property missing or `403 Forbidden` if unauthorized.
  - Validates file extensions (`.jpg`, `.jpeg`, `.png`, `.webp`) and max file size (5MB per file). Throws `ValidationException` resulting in `400 Bad Request` ProblemDetails.
  - Saves uploaded files to disk under `wwwroot/uploads/properties/` with unique filenames (`{propertyId}_{guid}{ext}`).
  - Updates `Property.ImageUrls` list and updates `UpdatedAt` timestamp.
- **`DeletePropertyImageCommand.cs` & `DeletePropertyImageCommandValidator.cs`**:
  - Checks ownership (`OwnerId == currentUserId` or `IsAdmin`).
  - Validates `PropertyId` and `ImageUrl`.
  - Removes target URL from `Property.ImageUrls` and deletes physical file from `wwwroot/uploads/properties/` if present.
- **`SetPrimaryPropertyImageCommand.cs` & `SetPrimaryPropertyImageCommandValidator.cs`**:
  - Checks ownership (`OwnerId == currentUserId` or `IsAdmin`).
  - Validates `PropertyId` and `ImageUrl`.
  - Reorders `Property.ImageUrls` placing target image URL at index 0 (`primaryImageUrl`).

### 3. Project Configuration & Web API Endpoints (`src/Web/`)
- **`Program.cs`**:
  - Configured `app.UseStaticFiles()` to serve static uploaded files from `wwwroot`.
  - Updated `Application.csproj` to reference `Microsoft.AspNetCore.App` framework for ASP.NET Core web host and form file features.
- **`PropertyEndpoints.cs`**:
  - **`POST /api/properties/{id}/images`**: Multi-part image upload endpoint (.RequireAuthorization(), .DisableAntiforgery()).
  - **`DELETE /api/properties/{id}/images`**: Image removal endpoint (.RequireAuthorization()).
  - **`PUT /api/properties/{id}/images/primary`**: Primary image setting endpoint (.RequireAuthorization()).
