# Handoff Documentation: FE-004 — Favorites, My Favorites Page & Inquiry Modal UI

## Summary
Task **FE-004** implements full user bookmarking (Favorites) functionality, the My Favorites page, property inquiry modal UI, and the user's submitted inquiries page in the Angular frontend for Aleppo Real Estate (`c:\Users\LEGION\Desktop\Aleppo Real Estate\src\Web\ClientApp`).

## Implemented Components & Services

### 1. Data Models (`src/app/core/models/`)
- `favorite.model.ts`:
  - `FavoriteResponse`: `{ propertyId: string; isFavorite: boolean; }`
  - `FavoriteItem`: `{ propertyId: string; property?: Property; addedAt?: string; }`
- `inquiry.model.ts`:
  - `CreateInquiryRequest`: `{ propertyId: string; message: string; phoneNumber: string; }`
  - `InquiryDto`: `{ id: string; propertyId: string; propertyTitle: string; userId: string; userName: string; message: string; phoneNumber: string; createdAt: string; }`

### 2. Angular Services (`src/app/core/services/`)
- `FavoriteService` (`favorite.service.ts`):
  - Angular Signals: `favorites`, `loading`, `favoriteIds`, `favoritesCount`.
  - Methods: `loadFavorites()`, `addFavorite()`, `removeFavorite()`, `toggleFavorite()`, `isFavorite()`.
  - Offline / Dev fallback support (`isDevMode()`) with `localStorage` persistence.
- `InquiryService` (`inquiry.service.ts`):
  - Angular Signals: `inquiries`, `loading`.
  - Methods: `createInquiry()`, `getMyInquiries()`.
  - Offline / Dev fallback support (`isDevMode()`) with `localStorage` persistence.

### 3. Components (`src/app/features/` & `src/app/core/`)
- **`PropertyCardComponent`** (`src/app/features/properties/property-card/`):
  - Added reactive Heart button for bookmarking favorites with scale/pulse animation and state binding.
  - Added Inquiry button ("استفسار") triggering `(openInquiry)` event.
  - Automatic redirect to `/login` if unauthenticated user attempts to favorite or inquire.
- **`FavoritesComponent`** (`src/app/features/favorites/`):
  - Standalone page for route `/favorites`.
  - RTL Arabic grid displaying saved properties using modern Angular `@if` / `@for` control flow.
  - Shows loading skeleton loaders, empty state ("لا توجد عقارات في المفضلة"), and item counter.
  - Integrated with `InquiryModalComponent`.
- **`InquiryModalComponent`** (`src/app/features/inquiries/inquiry-modal.component.ts`):
  - Standalone dialog component for sending property inquiries.
  - Reactive form (`message`, `phoneNumber`) with Arabic validation messages.
  - Loading spinner state during submission and success notification feedback.
- **`MyInquiriesComponent`** (`src/app/features/inquiries/my-inquiries.component.ts`):
  - Standalone page for route `/inquiries`.
  - Displays user's submitted inquiries with property title, date, message, phone number, and status indicator.
- **`HeaderComponent`** (`src/app/core/components/header/`):
  - Updated navigation bar to render links to "المفضلة" (with dynamic item count badge) and "استفساراتي" when user is authenticated.

### 4. Routing & Guards (`src/app/app.routes.ts`)
- Added protected routes guarded by `authGuard`:
  - `{ path: 'favorites', component: FavoritesComponent, canActivate: [authGuard] }`
  - `{ path: 'inquiries', component: MyInquiriesComponent, canActivate: [authGuard] }`
