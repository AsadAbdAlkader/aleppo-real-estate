3. **CQRS Application Layer (`src/Application/Chat/`):**
   - **DTOs:**
     - `ChatMessageDto.cs`: `id`, `senderId`, `receiverId`, `propertyId`, `propertyTitle`, `message`, `isRead`, `createdAt`.
     - `ChatConversationDto.cs`: `otherUserId`, `otherUserName`, `otherUserRole`, `otherUserPhone`, `lastMessage`, `unreadCount`, `lastMessageTime`, `propertyId`, `propertyTitle`.
     - `SendChatMessageRequestDto.cs`: `receiverId`, `propertyId`, `message`.
   - **Queries:**
     - `GetMyConversationsQuery.cs`: Extracts `CurrentUserId` from JWT claims, groups chat messages involving `CurrentUserId`, projects `ChatConversationDto` with unread count (`ReceiverId == currentUserId && !IsRead`) and `lastMessageTime` descending using `AsNoTracking()`.
     - `GetConversationMessagesQuery.cs`: Fetches message history between `CurrentUserId` and `OtherUserId` (optionally filtered by `PropertyId`), automatically marks incoming unread messages as `isRead = true`, and returns `List<ChatMessageDto>` ordered by `CreatedAt` ascending using `AsNoTracking()`.
   - **Commands:**
     - `SendChatMessageCommand.cs` & `SendChatMessageCommandValidator.cs`: Validates `ReceiverId` and `Message` (required, max 4000 chars), verifies receiver user existence, creates `ChatMessage` entity, automatically creates system `Notification` entity (`Type == "ChatMessageReceived"`), and saves changes atomically in one transaction.
