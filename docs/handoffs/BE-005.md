## Key Changes & Implementations

### 1. Domain Entity (`Domain/Entities/Property.cs`)
- Added `OwnerId` (`string?`) and navigation `Owner` (`User?`).

### 2. Dtos & Models (`Application/Properties/`)
- Updated `PropertyDto.cs` to include `public string? OwnerId { get; set; }`.
- Created `PropertyCommandResult.cs` (`UpdatePropertyResult`, `DeletePropertyResult`, `PropertyCommandStatus`) to represent outcomes cleanly without unhandled exceptions.

### 3. CQRS Commands & Queries (`Application/Properties/`)
- **`CreatePropertyCommand.cs`**:
  - Automatically sets `OwnerId` from JWT claim (`NameIdentifier` / `sub`).
- **`GetMyPropertiesQuery.cs`**:
  - Retrieves property listings where `OwnerId == currentUserId` ordered by creation timestamp descending.
- **`UpdatePropertyCommand.cs` & `UpdatePropertyCommandValidator.cs`**:
  - Enforces ownership verification (`OwnerId == currentUserId` or `IsAdmin`).
  - Returns `403 Forbidden` if user is not the owner, `404 Not Found` if property does not exist, or `200 OK` with updated `PropertyDto`.
- **`DeletePropertyCommand.cs`**:
  - Enforces ownership verification (`OwnerId == currentUserId` or `IsAdmin`).
  - Removes entity upon authorization or returns `403 Forbidden` / `404 Not Found`.

### 4. REST Web API Endpoints (`Web/Endpoints/PropertyEndpoints.cs`)
- `GET /api/properties/my`: Retrieves listings of authenticated user (`.RequireAuthorization()`).
- `POST /api/properties`: Creates property listing assigned to current user (`.RequireAuthorization()`).
- `PUT /api/properties/{id}`: Updates property listing with ownership check (`.RequireAuthorization()`).
- `DELETE /api/properties/{id}`: Deletes property listing with ownership check (`.RequireAuthorization()`).

### 5. Infrastructure & Database (`Infrastructure/Data/`)
- Configured `Property.OwnerId` index and property rules in `ApplicationDbContext.cs`.
- Updated `ApplicationDbContextInitialiser.cs` to assign `OwnerId` to initial seeded properties.
